# Contenido de la web de Jota (archivo)

Se guarda para reutilizarlo en la web de Fogar con otra presentación. No se importa desde ninguna página.

- `article.{es,en}.ts`: el artículo «Cómo está hecho» (arquitectura, piezas y cómo encajan).
- `index.{es,en}.ts`: el índice del apartado DIY.
- `textos-web.{es,en}.json`: todos los textos de la home y de la página de Jota-Screen.

Los nombres son los antiguos (Jota, Jota-Screen…): al reutilizarlos se pasan a Fogar según las reglas de la migración.
Las páginas y componentes originales siguen en el historial de git (commit `3d39976`).
