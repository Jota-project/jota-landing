# fogar-landing

La web de Fogar: Next 16, React 19, Tailwind 4 y next-intl (español e inglés, sin prefijo en la URL).

```bash
pnpm install
pnpm dev
pnpm test
```

- `app/[locale]/`: la página pública.
- `app/lab/`: prototipos sin indexar (por ejemplo `/lab/secuencia`, el vídeo de fondo sincronizado con el scroll).
- `app/fogar-tokens.css`: copia de los tokens de `fogar-brand`; no se edita aquí.

Specs, decisiones y estado del proyecto están en el vault de Obsidian, no en este repo.
